Профили модов

Профиль модов позволяет сохранить текущее состояние (включён/отключён) всех модов, чтобы применить его позже. Профили хранятся отдельно для каждой конфигурации.

Сохранение профиля модов

Чтобы сохранить текущее состояние модов как профиль, откройте меню «Моды», выберите «Профиль», затем «Сохранить текущий...». Откроется окно, в котором нужно указать параметры сохраняемого профиля.

Имя профиля модов
Имя, под которым будет сохранён новый профиль.


Применение профиля модов

Чтобы применить сохранённый ранее профиль, откройте меню «Моды», выберите «Профиль» и щёлкните нужный профиль. Каждый мод будет включён или отключён в соответствии с сохранённым профилем.

Удаление профиля модов

Чтобы удалить профиль модов, откройте меню «Моды», выберите «Профиль», затем «Удалить...». Откроется окно, в котором нужно выбрать удаляемый профиль.
