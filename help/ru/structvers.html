Версии модов

OvGME поддерживает версии для мод-архивов (но не для мод-папок). Локально версия мода задаётся строкой в специальном текстовом файле в корне zip-файла мод-архива либо данными из репозитория. Версия используется механизмом репозиториев, чтобы определить, какая из версий одного и того же мода новее.

Файл version.txt

OvGME автоматически проверяет, есть ли в корне zip-файла мод-архива файл «version.txt». Если он есть, его содержимое считается строкой версии мода. Это должен быть обычный текстовый файл ASCII, а строка версии должна соответствовать описанному ниже формату.

Формат строки версии

Строка версии должна содержать только цифры, при необходимости разделённые точками; буквы и другие специальные символы не допускаются.

Допускается до трёх компонентов версии, разделённых одной (и только одной) точкой, по стандартной схеме нумерации версий GNU:
старшая.младшая.ревизия
Строка версии не обязана содержать все три компонента: например, может быть указана только старшая и младшая версия или даже одно число, которое считается старшей версией.
Примеры допустимых строк версии:
1.5.0
1.2
2
0.9.5
0.9
Правила разбора строки:
  • Если чисел три, они по порядку означают:
    старшая версия . младшая версия . ревизия
  • Если чисел два, они по порядку означают:
    старшая версия . младшая версия
  • Если число одно, оно означает:
    старшая версия

Сравнение версий

OvGME автоматически определяет, какая версия новее, сравнивая по порядку старшую, младшую версию и ревизию. Если строки версий имеют разный формат, действует правило: недостающие компоненты справа от старшей версии равны 0.

Например, строка «1.2» численно означает 1.2.0, а строка «2» — 2.0.0. Поэтому:
при сравнении «1.2» (1.2.0) и «1.2.1» новее считается «1.2.1».

При сравнении «1.2.2» и «1.3» новее считается «1.3» (1.3.0).

При сравнении «1» и «0.5.5» новее считается «1» (1.0.0).
