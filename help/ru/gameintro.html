Введение

OvGME позволяет из одного окна управлять модами для нескольких игр, программ или любых других папок. Конфигурация задаёт параметры для одной рабочей папки. Конфигурация состоит из трёх компонентов: корневой папки, папки с модами и папки резервных копий.

Корневая папка

Корневая папка — это место, куда OvGME устанавливает моды при их включении. Это может быть папка установки игры или программы либо любая другая папка, в которой моды должны произвести изменения.

Папка с модами

В папке с модами OvGME ищет доступные моды. Именно здесь нужно хранить моды для данной корневой папки (т. е. игры, программы и т. п.)

Папка резервных копий

В папке резервных копий OvGME хранит все оригинальные файлы корневой папки (т. е. игры, программы и т. п.), которые были изменены установленными модами. По умолчанию OvGME хранит резервные копии в собственной внутренней структуре (ProgramData\OvGME), но для каждой конфигурации можно выбрать свою папку резервных копий.

Примечание: путь к корневой папке у каждой конфигурации должен быть уникальным — нельзя создать несколько конфигураций для одной и той же корневой папки.
