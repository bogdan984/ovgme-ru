Создание модов

OvGME содержит инструмент для создания корректного мод-архива (zip) из существующей мод-папки. Мод-папка уже должна иметь правильную структуру, описанную в разделе Структура модов.

Из главного меню

Откройте меню «Моды» и выберите «Создать мод-архив...». Откроется соответствующее окно.

Из контекстного меню

Выделите в списке модов мод-папку, которую хотите превратить в мод-архив, и нажмите правую кнопку мыши. В контекстном меню выберите «Создать мод-архив...».
Исходная мод-папка
Путь к мод-папке, которую нужно упаковать в zip-архив. Это папка, содержащая повторяющее корневую папку дерево с изменёнными файлами.

Куда сохранить zip-файл
Путь к папке, в которой будет создан zip-файл мод-архива.

Номер версии мода
Версия мода для этого выпуска. Это значение используется репозиториями. Строка версии будет записана в файл version.txt в корне мод-архива.

Описание / Readme этого мода
Необязательное описание мода. Если описание заполнено, в корень мод-архива будет добавлен соответствующий .txt-файл, который OvGME автоматически распознаёт как описание мода.

Уровень сжатия zip
Метод сжатия zip, используемый при создании мод-архива.

Указав нужные значения, нажмите кнопку «Создать», чтобы начать создание архива. Процесс можно отменить в любой момент.

Примечание: если мод содержит много больших файлов, процесс может занять некоторое время, так как все файлы сжимаются в формат Zip. Примечание: из-за ограничения программы имя мод-папки и путь к архиву должны состоять только из латинских символов — с кириллицей в имени создание архива завершится ошибкой.
