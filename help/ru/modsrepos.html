Репозитории модов

OvGME позволяет подключать удалённые репозитории модов, чтобы загружать новые моды и обновления. В этом разделе описана только клиентская часть. Если вы хотите сами размещать репозиторий и управлять им, смотрите раздел «Управление репозиториями».

Репозитории модов — это удалённые веб-серверы, с которых можно загружать моды и их обновления. Чтобы OvGME распознал такой сервер при опросе, он должен быть совместим с OvGME.

Примечание: репозитории предоставляются третьими лицами, у OvGME нет репозитория по умолчанию (см. «Управление репозиториями»).

Настройка репозиториев

Чтобы настроить удалённые репозитории для текущей конфигурации, откройте меню «Моды», выберите «Репозитории», затем «Настроить...». Откроется окно управления адресами (URL) репозиториев.
Примечание: список репозиториев не глобальный — у каждой конфигурации свой список. Репозитории, настроенные для одной конфигурации, действуют только для неё.
Добавление и удаление URL
Чтобы добавить новый URL репозитория, введите его в поле URL и нажмите кнопку «Добавить». URL должен указывать на HTTP-сервер. Примеры допустимых форматов URL:
"http://www.example.com/repos"
"www.example.com:8080/repository/dcs"
"http://192.168.0.1:80/mods"
Чтобы удалить URL репозитория, выделите его в списке и нажмите кнопку «Удалить».
Включение и отключение URL
Репозитории можно включать и отключать для опроса. Отключённый репозиторий не проверяется при опросе, но остаётся в списке для дальнейшего использования.
Чтобы включить или отключить URL репозитория, установите или снимите флажок рядом с ним в списке.

Опрос репозиториев

При опросе OvGME обращается к каждому включённому репозиторию и составляет список модов, доступных для загрузки или обновления. Чтобы опросить репозитории, откройте меню «Моды», выберите «Репозитории», затем «Опросить...». Откроется новое окно.

OvGME автоматически начнёт опрос. Когда он успешно завершится, в списке появятся моды. Значок у каждой записи показывает её состояние относительно локальной папки с модами этой конфигурации.
— мода нет в локальной папке, его можно загрузить.
— мод уже есть в локальной папке, и версия совпадает.
— мод уже есть в локальной папке, но его версия ниже, чем в репозитории (мод можно обновить).
— мод уже есть в локальной папке, но его версия выше, чем в репозитории (загрузка этого мода откатит локальную версию).
Загрузка модов
Чтобы загрузить мод из репозитория, просто дважды щёлкните по нему в списке. Можно также выделить несколько модов и нажать кнопку «Загрузить выбранные». Наконец, чтобы синхронизировать всю локальную папку с модами, нажмите кнопку «Загрузить все».

В зависимости от этапа установки загружаемый мод может иметь разные состояния.
В очереди... — мод находится в списке загрузки и ожидает обработки.
Отключение старого... — текущий локальный мод удаляется: перед обновлением или откатом мод нужно отключить.
Загрузка... — мод загружается.
Возможные состояния ошибок:
Узел не найден — загрузка не удалась: не удалось определить адрес сервера.
Ошибка соединения — загрузка не удалась из-за ошибки подключения к серверу.
Ошибка передачи HTTP — загрузка не удалась из-за неподдерживаемой кодировки передачи HTTP (подробнее см. ниже).
Ошибка HTTP ### — загрузка не удалась: сервер вернул ошибку HTTP (обычно 404 — не найдено).
Соединение потеряно — загрузка не удалась из-за разрыва соединения.
Ошибка открытия файла — загрузка не удалась: не удалось создать файл на локальном диске.
Ошибка записи файла — загрузка не удалась: не удалось записать данные в файл на локальном диске.
