Вопросы о репозиториях

Поддерживает ли OvGME серверы HTTPS?

Нет. OvGME поддерживает только стандартный протокол HTTP.

Можно ли разместить несколько репозиториев на одном сервере (сайте)?

Да. OvGME смотрит только на XML-файлы по указанным URL и не зависит от веб-сервера, поэтому в одном месте можно разместить сколько угодно XML-файлов. Например, если вы хотите вести репозитории для нескольких программ или нескольких списков модов, сделайте отдельный XML-файл для каждого:
http://www.example.com/main (.xml)
http://www.example.com/updates (.xml)
http://www.example.com/special (.xml)
и т. д.

Поддерживает ли OvGME динамически формируемые XML-данные (страницы PHP / ASP)?

Да. Начиная с версии 1.6 OvGME может получать XML-данные с любой динамически формируемой веб-страницы, например PHP или ASP, но URL репозитория должен быть явным. Подробнее см. раздел «Принцип работы репозитория».

Должен ли сервер репозитория хранить и zip-файлы мод-архивов?

Нет. Как сказано в разделе «XML-данные репозитория», URL модов в XML никак не связаны с URL репозитория. Сервер репозитория отдаёт только XML-файл «базы данных». Zip-файлы мод-архивов могут находиться и загружаться с любого другого веб-адреса.

Поддерживает ли OvGME загрузку и обновление модов, которые не являются zip-архивами?

Пока нет. OvGME работает только с zip мод-архивами. При работе с репозиториями (проверка имён, сравнение версий и т. д.) обычные мод-папки просто игнорируются. Можно сказать, что поддержка мод-папок предназначена в основном для авторов модов и облегчает разработку (распакованную структуру папок изменять проще, чем zip-архив).

Можно ли использовать репозитории в локальной сети?

Да, OvGME работает как (очень) простой HTTP-клиент (веб-браузер). Нужен лишь HTTP-сервер в вашей локальной сети. Если в локальной сети нет службы доменных имён (так бывает часто), просто укажите в качестве URL репозитория IP-адрес сервера, например: «http://192.168.0.5/repository/main»

Должно ли имя загружаемого zip-файла совпадать с именем мода в XML-файле?

Нет. OvGME не важно имя загружаемого файла: после загрузки файл переименовывается по указанному имени с расширением «.zip». Например, если в XML-файле указано имя мода «My Super Mod», а URL загрузки — «http://www.ex.net/super-mod-v1_0.zip», загруженный файл будет переименован в «My Super Mod.zip» и появится в списке модов как zip мод-архив «My Super Mod».
