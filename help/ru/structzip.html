Мод-архив

Мод-архив — это, по сути, упакованная в zip корректная мод-папка. Однако OvGME нужно правильно сопоставить дерево файлов мода с деревом корневой папки и понять, где искать данные, поэтому корректный мод-архив должен соответствовать нескольким простым правилам. Если они не соблюдены, zip-файл не будет распознан как мод-архив.

  • Файл ДОЛЖЕН быть сжат в формате ZIP.
    Сейчас OvGME поддерживает только архивы стандартного формата ZIP.

  • В корне zip-файла ДОЛЖНА быть правильно названная папка-контейнер.
    В корне архива должна лежать папка-контейнер (а не сами файлы мода). Кроме того, эта папка должна называться так же, как сам архив, но без расширения .zip. Например, если архив называется «My Super Mod.zip», в нём должна быть папка-контейнер «My Super Mod» с файлами мода. OvGME не может угадать, какую папку архива считать корневой, а мод-архив может содержать и другие файлы помимо изменённых файлов корневой папки, поэтому OvGME ищет папку с именем, точно совпадающим с именем zip-файла. Таково соглашение.

  • Zip-файл может содержать файл описания.
    OvGME автоматически проверяет, есть ли в корне zip-файла правильно названный .txt-файл. Если он называется «description.txt», «readme.txt» или точно так же, как корневая папка мода или сам zip-файл (но с расширением .txt вместо .zip), он используется как описание мода. Это должен быть обычный текстовый файл ASCII: форматированный текст OvGME пока не поддерживает.

  • Zip-файл может содержать файл версии.
    OvGME автоматически проверяет, есть ли в корне zip-файла файл «version.txt». Если он есть, его содержимое считается строкой версии мода. Это должен быть обычный текстовый файл ASCII, а строка версии должна соответствовать формату из раздела «Версии модов».

Например, если дерево файлов корневой папки такое:

📁 MyGame
   📁 Textures
     📁 Landscape
       📄 picture1.dds
       📄 picture2.dds
     📁 Vehicles
       📄 picture1.dds
       📄 picture2.dds
и мод заменяет несколько текстур .dds в «MyGame\Textures\Vehicles», то zip-файл мод-архива должен быть устроен так:
📂 My Texture Mod.zip
{
   📄 README.txt (необязательно)
   📄 VERSION.txt (необязательно)
   📁 My Texture Mod
     📁 Textures
       📁 Vehicles
         📄 picture1.dds
         📄 picture2.dds
}
Затем файл «My Texture Mod.zip» нужно скопировать в папку с модами этой конфигурации или импортировать с помощью функции импорта.

Примечание: для создания мод-архива можно воспользоваться инструментом OvGME — он сам создаст zip-файл с правильной структурой из существующей мод-папки (см. раздел Создание модов).
